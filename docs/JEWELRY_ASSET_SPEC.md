# 4EVER · 试戴素材规范 / JEWELRY ASSET SPEC

适用范围：`src/assets/jewelry/` 下所有饰品素材，以及任何后续生成的素材。

**这是一份佩戴素材规范，不是商品展示图规范。**

编辑器把素材直接叠在用户的真实耳朵照片上，所以素材里出现任何"耳朵之外的东西"，
用户都会立刻看到，真实感就没了。生成素材时请默认：

> transparent background · front wearable view · isolated jewelry only

---

## 1. 禁止出现的内容

| 禁止 | 说明 |
| --- | --- |
| 耳针 / 针脚 | STUD 只保留正面装饰部分，不要画穿过耳洞的针 |
| 耳堵 / 耳背 / 蝴蝶扣 | 佩戴时在耳朵后面，照片里根本看不到 |
| 包装盒、绒布、卡片 | 不属于佩戴视角 |
| 模特、人脸、耳朵 | 耳朵由用户自己上传 |
| 手、手指、镊子 | 同上 |
| 商品卡片、价签、水印 | 同上 |
| 文字、logo、品牌标 | 画布上任何字符都不允许 |
| 投影阴影 / 地面倒影 | 会浮在耳朵照片上，看起来像贴纸 |

## 2. 必须满足的技术要求

- **透明背景**：背景 alpha = 0，不能用白底、黑底或"看起来像透明"的浅灰底。
  主体 alpha 应接近 255（允许边缘抗锯齿过渡），不要整体半透明。
- **正方形画布**：建议 1254×1254 或 1024×1024，方便编辑器按统一边长缩放。
- **正面佩戴视角（front wearable view）**：正对镜头，不要 3/4 侧视、不要俯视。
- **单件独立**：一张图只有一件饰品，不要成对、不要组合排列。
- **水平垂直居中**：主体占画布约 70%–85%，四周留出等量留白，
  主体不要贴边、不要被裁切。
- **文件格式**：PNG-24 带 alpha 通道。不要 JPEG。

## 3. 分类要求

| 分类 | 代码 | 生成要求 |
| --- | --- | --- |
| 耳钉 | `STUD` | **只有正面装饰部分**。星形、晶体、珍珠、翅膀等正面造型，没有针、没有耳堵。 |
| 耳环 | `HOOP` | 完整环体正面视图，含开口 / 卡扣结构，环内为透明。 |
| 链饰 | `CHAIN` | 从上端挂点向下垂落的链条，上端即吸附点。链环之间要通透，不要实心色块。 |
| 耳骨夹 | `CUFF` | 只画夹在耳廓外侧可见的弧线部分，不画内侧结构。 |

## 4. 视觉方向

银色 · 珍珠 · 透明水钻 · 冷色金属。

气质关键词：`cyber angel` / `dreamcore` / `old software archive`。

- 金属：偏冷的银、钛、做旧钢，反射清晰但不要过曝成纯白。
- 珍珠：乳白偏冷，带一点虹彩，不要暖黄。
- 水钻：透明无色，靠高光和边缘线表达，不要彩色宝石。
- 避免：暖金、玫瑰金、饱和度高的彩色、卡通描边、粗糙像素感。

## 5. 命名

`分类-材质-造型.png`，全小写，连字符分隔，例如：

```
stud-pearl-orbit.png
hoop-silver-clicker.png
chain-ice-drop.png
cuff-crystal-arc.png
```

- [ ] 是正面佩戴视角
- [ ] 银色 / 珍珠 / 透明水钻 / 冷色金属方向

## 8. 改素材不会影响编辑器

`src/data/jewelry.js` 只记录 `source / type / size / scale`，替换 PNG 不需要改任何逻辑。
素材进入画布的唯一入口是 `src/services/image.js` 的 `preprocessJewelryImage()`，
目前刻意不做任何像素处理（自动抠色会削掉金属边缘的抗锯齿）。
